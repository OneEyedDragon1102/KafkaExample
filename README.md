# KafkaExample

### navigate to kafka folder and open terminal and type `.\bin\windows\kafka-server-start.bat .\config\server.properties`

### open new terminal in kafka folder and run 2 cmds
1. `set KAFKA_HEAP_OPTS=-Xmx1G -Xms1G` or you can use 512M.
2. `.\bin\windows\kafka-server-start.bat .\config\kraft\server.properties`

### run the application in intelliJ

### Use endpoint http://localhost:8080/send?message=HelloKafka from local machine to send message.

### review logs in IDE terminal.
